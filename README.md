# 夏一跳的影视基地

这里放夏一跳实际使用的 AI 短剧制作流程、提示词和 Skill。

目标很简单：把一集短剧从剧本，做到人物、场景、道具资产，再做到视频和剪辑。

## 目前内容

- `skills/script-asset-supervisor.md`：从剧本整理并生成图片资产
- `skills/seedance-2-0-prompts.md`：Seedance 2.0 视频提示词
- `skills/seedance-2-5-prompts.md`：Seedance 2.5 视频提示词
- `resources.md`：相关 Skill 和外部资料链接

这套内容来自实际制作，会继续更新。

## 基本流程

1. 把剧本交给 Codex 或其他支持本地记忆的智能体。
2. 先整理人物、场景、道具等资产清单。
3. 确认清单后，生成图片资产。
4. 根据剧本和资产，拆出视频提示词。
5. 在即梦中生成视频，再用剪映拼接检查。

## 工具

- ChatGPT / Codex：剧本整理、资产规划、提示词和图像生成
- 即梦 / Dreamina：视频生成
- 剪映 / CapCut：剪辑和拼接
